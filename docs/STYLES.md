# 风格与触发词

| 风格 | 适用内容 | 推荐触发说法 |
|---|---|---|
| 自然肤色 Q 版人物故事 | 人物传记、历史、创业故事 | “用 Q 版人物逐笔讲完他的一生，不要黑脸，年龄要变化” |
| Nikola 怪诞小黑草图 | 方法、观点、抽象系统、冷幽默隐喻 | “用 Nikola 怪诞小黑草图，边讲边画，白底少量彩色批注” |
| 双语义岛 | 左右因果、问题/答案、前后转折 | “先画左边边讲，再画右边，写关键短词” |
| 程序化知识图形 | 流程、规则、关系、精确标签 | “做成手绘风流程卡片动画，文字必须准确可控” |

“手绘风”不自动等于逐笔绘制。用户说“一笔一笔”“笔尖跟随”“边讲边画”时使用逐笔模式；用户强调独立卡片、箭头、精确标签和元素变换时使用程序动画。

详见 [自然肤色 Q 版人物](../references/q-human-story-style.md)、[Nikola 怪诞小黑](../references/nikola-absurd-sketch-style.md) 和 [双语义岛](../references/semantic-island-storytelling.md)。
